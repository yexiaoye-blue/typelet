# 产品与技术范围

截至 2026-10-14，当前实现保持为跨平台、小巧悬浮窗和本机文本练习。本文描述现有功能；已确认的后续方向见 [后续规划](roadmap.md)。

打开一个 380 × 450 的桌面小窗，默认置顶，可以拖动标题栏移动。选择中文或英文练习，直接点击练习文字跟打，不再显示独立输入框。已打正确字符使用正文颜色，待打字符使用灰色，当前字符显示淡蓝底色和主色下划线，错误字符显示红色底块，允许退格修改。标记绘制在字符自身范围内，连续错字间留出细缝，文字区保留边缘留白，避免行首裁切和相邻标记重叠。输入法组字在当前位置临时显示，提交后更新统计。打完一段停止计时，点击“换一段”或按回车继续。

窗口不拦截全局键盘，不监听其他应用，不自动弹出。离开输入框、最小化或切走窗口暂停计时；返回后点击输入框继续。没有关卡、敌人、作品收藏或代码编辑器。

应用为单实例：已在运行时再次启动，第二个进程会把请求交给第一个实例并立即退出，由第一个实例显示、还原并聚焦已有窗口。因此任何能够执行命令的脚本都可以通过运行 typelet 唤起窗口，不会叠加出多个练习窗口。启动时由 Rust 侧在 setup 中主动显示并请求窗口焦点，避免出现窗口已打开但键盘输入还没进来的情况。

练习正文设置 user-select: none，拖动不会产生文本选区。练习页内按下鼠标后，无论松手位置在窗口内还是窗口外，都会在窗口的 pointerup 阶段把焦点交回隐藏输入框，窗口重新获得焦点时同样回到输入状态。这样点击标题栏拖动窗口、或从其他应用切回来后，不必再点一下输入区域就能继续打字，当前位置标记也不会因焦点丢失退化为暂停样式。

主页面顶部只显示速度、正确率和用时。练习文字下方、操作按钮上方放置一条 2px 的进度条，不再显示进度标题或百分比；进度数值继续通过原生进度条提供给辅助阅读工具。

## 技术

- Svelte + TypeScript：小窗界面、输入事件、计时显示和交互状态。
- Rust core：文本匹配、累计输入正确率、当前有效字符速度和完成判断。
- Tauri 2：Windows / macOS / Linux 桌面窗口、拖动、置顶、最小化、关闭和打包。
- Vite：前端开发和构建，生产资源由 Tauri 加载。
- 字体：内置 Noto Sans Mono，Rust 通过 font-kit 读取系统字体家族，字体选择仅影响练习文字。开发预览提供本机字体家族列表接口。

每次输入通过一个 Tauri command 请求 Rust core 返回练习快照。网页预览模式保留 TypeScript 回退，方便只启动 Vite 调整界面；桌面运行时以 Rust 结果为准。应用不监听其他应用的键盘，不连接网络，也不引入 Agent hooks。

中文以 Unicode 码点计数，不使用 UTF-16 长度；内置练习不包含复杂 emoji。英文空格和标点也计为字符。速度单位是字符 / 分，按当前正确字符数除以实际练习时间计算；不足一秒显示 0。正确率按累计提交字符统计，退格不会抹去之前的错误。不接受粘贴和拖入文本，以免影响练习统计。

右上角设置页提供明暗色与中英文界面切换，默认跟随系统；练习字体可搜索、选择系统字体并预览。设置保存在本机。练习语言在主页面单独选择。打开设置暂停计时，返回后保留当前练习。本版不保存输入进度或练习历史。

## 边界

Rust core 保持为纯函数 crate，与 Tauri 桌面窗口分开测试。窗口由系统 WebView 渲染，跨平台打包配置不等于三个系统都已验证；发布签名、安装包验收、真实中文输入法和不同窗口系统需要分别记录。

当前版本在设置中支持 Codex 任务自动唤起，不读取会话内容。开启时由 Rust 侧在用户主目录的 .codex/config.toml 中维护 Typelet 自己的 UserPromptSubmit 配置块；提交任务时运行 typelet，关闭时只删除这一个标记块，不修改其他 Codex hooks。Codex 可能把新增 hook 标记为未信任并要求用户确认一次，这是 Codex 的安全机制。当前只接入 Codex，其他 Agent 的接入方式仍待设计。单词发音、翻译和内容导入仍待后续实现。
