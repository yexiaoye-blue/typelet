# 产品与技术范围

截至 2026-11-02。使用和安装见 [README](../README.md)，详细格式见 [导入说明](importing.md)。本文只记录当前边界，不再把句子、单词和导入当成后续计划。

练习窗口默认 380 × 450，标题栏可拖动；在支持的桌面环境中可以置顶。应用是单实例：再次启动会显示并聚焦已有窗口。练习正文不能选中。点击发音或从别的区域回到窗口后，焦点回到输入区。

设置里用分段控件切换句子和单词。单词独有的音标口音和「自动朗读并切换」只在单词模式出现。

句子模式一次一句。内置电影台词按电影分章，并显示中文释义。导入的 `.txt` 整篇作为一章。拼对后自动进入下一句。长句在固定高度里滚动，窗口高度不跟着句子变。

单词模式一次一词，默认每 20 个词一章。可在设置中调整每章数量，也可打乱当前章节中的顺序；已有电影章节保持原划分。显示所选口音的音标和释义。默认在开始练习后朗读当前词，拼对后进入下一个并朗读。有道读音失败时使用系统语音。

本章最后一项完成后暂停，练习区换成成绩，底部仍是本章的 WPM、正确率和用时，并播放一次彩屑。回车进入下一章并开始。未开始和手动暂停都会模糊练习区。窗口不再是当前焦点时自动暂停。

打到当前句子或单词的末尾时，即使有错字，回车也可以进入下一项。速度按本章累计用时里的正确字符数计算，标签是 WPM。

词本是单独一页，不是下拉框。预置和导入的内容都列在这里，导入前有预览。桌面端把词本选择、导入内容和练到的条目写在应用数据目录的 `content.json`。外观、语言、字体、单词朗读偏好，以及朗读音量、按键音开关、按键音量和音色，写在本机界面存储里。打到一半的输入不保存。

## 小窗与快捷键

桌面端支持小窗练习，保留内容、发音和开始/继续操作。默认 `Ctrl/⌘ + Shift + M` 切换小窗；完整窗口和小窗共享当前练习状态。

快捷键配置位于「设置 → 快捷键」二级页面，支持搜索、点击录制、冲突提示和恢复默认。配置立即保存在本机 WebView 存储中；返回一级设置时恢复滚动位置和入口焦点，离开配置页会清理录制状态。`Esc` 暂停与章末 `Enter` 继续为固定操作。

Linux 不再为置顶强制使用 XWayland。实际 GTK 后端由原生代码检测；GTK 3 Wayland 不支持置顶，此时完整窗口及小窗的置顶按钮禁用并提示原因。窗口焦点问题需用最终安装包实机复验，不能从网页截图推断。

## 技术

- Svelte + TypeScript 负责界面、焦点、计时展示和设置。
- Rust core 负责切句、词表解析、字符匹配、正确率和完成判断。桌面端每次输入向 Rust 要快照。
- Tauri 2 负责窗口、拖动、置顶、单实例和打包。
- Vite 提供网页预览。预览使用同一份内置 JSON 的 TypeScript 回退，不模拟本机文件导入、Agent 配置写入或原生窗口能力，浏览器进度与桌面数据独立。
- 内置 JSON 以紧凑文本编进程序。打包步骤不会再去掉空白，所以源文件本身保持一行。

中文按 Unicode 码点计数。不接受粘贴，避免统计失真。Codex 自动唤起只改本机 `~/.codex/config.toml` 的 UserPromptSubmit，不读取会话内容。Cursor 使用 `~/.cursor/hooks.json` 的 beforeSubmitPrompt。

## 边界

CET4_3 来自 kajweb/dict，数据出自有道 / 新东方，只用于本机练习，不原样再发布词书。按键音来自 Qwerty Learner 的 `public/sounds/key-sound`，录音出自 kbsim。DeepSeek Harness 已出现在设置里，还没有可用的任务 hook。不导入 EPUB、PDF、DOCX、HTML 或 Anki `.apkg`。当前 CI 发布 Windows MSI/NSIS、Linux DEB/AppImage 与 Fedora RPM 的 x86_64、aarch64 包；macOS 尚无 CI 安装包。macOS 和 Windows 的发布签名尚未配置，打包成功不等于各系统实机验收通过。
