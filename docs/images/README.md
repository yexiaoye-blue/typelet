# 界面截图

README 中的四张 PNG 来自真实运行的 `npm run web:dev`，使用全新隔离浏览器中的内置电影台词与 CET4_3 演示数据，没有读取桌面用户词本、进度或个人配置。

- `practice.png`：句子练习。
- `word-practice.png`：单词、音标与释义。
- `settings-shortcuts-entry.png`：一级设置正常向下滚动后，展示「快捷键」入口。
- `shortcuts.png`：快捷键二级配置页。

截图采用浅色中文界面、2 倍像素密度；两张练习图视口为 420 × 650，两张设置图为 420 × 760。演示时关闭声音，统计来自实际输入过程。网页预览不模拟原生窗口置顶、拖动、文件导入和 Agent 配置写入，不能用这些图片代替桌面实机验收。

更新截图时保留文件名，并检查根目录 README 的相对路径和显示效果。
