# 界面截图

四张 PNG 来自真实运行的 `npm run web:dev`，使用隔离浏览器中的内置电影台词和 CET4_3 演示数据，没有读取桌面用户词本、进度或个人配置。

| 文件 | 内容 |
| --- | --- |
| `practice.png` | README 主图：句子练习 |
| `word-practice.png` | 单词、音标和释义 |
| `settings-shortcuts-entry.png` | 一级设置滚动后的快捷键入口 |
| `shortcuts.png` | 快捷键二级配置页 |

全部使用应用实际的深色中文主题，2 倍像素密度。真实网页嵌在仅用于截图的展示框中：20px 圆角、细边框与透明留白；这不是原生桌面窗口截图，也没有修改应用源码中的布局或功能。

两张练习图的应用视口为 380 × 450，设置图为 380 × 650；外围各保留约 50px 空间。演示时关闭声音，统计来自实际输入过程。网页预览不模拟置顶、拖动、文件导入或 Agent 配置写入，图片不能代替桌面实机验收。

更新时保留文件名和相同的深色展示风格，检查 README 的相对路径、透明边缘与缩略图可读性。
