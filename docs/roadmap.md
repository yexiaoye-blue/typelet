## 1. Agent 运行时自动唤起

在设置中添加配置，让用户选择要响应哪些 Agent，并开启或关闭自动唤起。选中的 Agent 开始运行时，启动或显示 Typelet；应用已经打开时复用现有窗口。

第一版已经完成 Codex 和 Cursor：设置页列出 Codex、Cursor、DeepSeek Harness（dsh）三张卡片。Codex 使用 .codex/config.toml 的 UserPromptSubmit，Cursor 使用 .cursor/hooks.json 的 beforeSubmitPrompt；两者都支持开关、查看和编辑 Typelet 自己的配置片段。提交任务时会运行 typelet，单实例机制负责显示、还原并聚焦已有窗口。Codex 首次可能要求确认新增 hook。

后续继续确认 DeepSeek Harness 的插件或任务事件能力，再决定适配方式。不同 Agent 的 hooks 配置不假设存在统一格式，Typelet 会为每家保留独立的配置适配器。

## 2. 句子与单词模式

在设置中增加“句子 / 单词”两种练习模式。当前连续文本练习归入句子模式；句子模式内置几篇短的公有领域节选，文章也可以从 UTF-8 .txt 导入，Rust 负责文章切句，一次练习一句。单词模式一次展示一个英文单词，显示音标和释义，保留当前的字符反馈与基本统计。

单词模式使用 [kajweb/dict](https://github.com/kajweb/dict) 转换出的 CET4_3 2607 词扁平词条，不把约 72 MB 原库打进应用。词条字段为 name、trans、usphone、ukphone；数据来源和无许可证限制见 [内容与练习模式实现规划](content-plan.md)。

已确认：

- 完成单词后默认朗读一次，不自动跳词；按回车才换下一个词。
- 发音首选有道 https://dict.youdao.com/dictvoice?audio=单词&type=2，失败或离线时使用系统语音。
- 单词模式仅英文；本轮不做章节格子、错词本和听写隐藏。
- 可以记住选中的文章和词书，不保存打到一半的输入。

## 3. 自定义内容导入

允许用户导入自己的句子文章或词库，并在对应练习模式中使用。导入后的内容也应能继续在小窗中练习，内容读取、解析、切句和词序切片由 Rust 完成。

已确认的导入格式：

- 句子文章：UTF-8 纯文本 .txt，一个文件一篇文章；文件名作为默认标题，Rust 按统一规则清理和切句。
- 单词词表：带表头的 UTF-8 TSV，扩展名建议 .tsv，也接受 .txt；name 必填，trans、usphone、ukphone 可选，每行一个词条。只有单词时使用只有 name 列的文件。
- 文章和词表都不直接支持 EPUB、PDF、DOCX、HTML 或 Anki .apkg；这些格式的版式、媒体或复习状态超出当前小窗练习边界。
- 导入入口需要文件对话框、预览、错误行提示、重复词条报告和本机保存；已选文章/词书可记住，半途输入不保存。
